# 3. Подключение клиентов

## WireGuard (файлы `client*.conf` из `~/wg-clients/`)

| Платформа | Приложение | Как импортировать |
|---|---|---|
| iOS | WireGuard (App Store, бесплатно) | «+» → «Создать из QR-кода» → сканировать `client1.png` |
| Android | WireGuard (Google Play / F-Droid) | «+» → «Сканировать QR-код» |
| Windows | WireGuard for Windows | «Add Tunnel» → «Import tunnel(s) from file» → `client1.conf` |
| macOS | WireGuard (App Store) | «+» → «Импорт туннеля из файла» |
| Linux | `sudo apt install wireguard` | `sudo cp client1.conf /etc/wireguard/wg0.conf && sudo wg-quick up wg0` |
| Роутер Keenetic | «WireGuard VPN» в веб-интерфейсе | загрузить `.conf` |
| OpenWrt | `opkg install wireguard-tools` | тот же `.conf` в `/etc/wireguard/` |

Проверка: в приложении должен появиться «Последнее рукопожатие» (latest handshake)
и счётчик трафика. На сервере — `wg show`.

## AmneziaWG

Клиенты: приложение **AmneziaVPN** (Windows, macOS, Linux, Android, iOS) или
**AmneziaWG** (Android/iOS, форк WireGuard-клиента). Правильный способ — импорт
**файла или QR-кода**: в конфиге кроме обычных полей есть 9 параметров обфускации
(`Jc`, `Jmin`, `Jmax`, `S1`, `S2`, `H1`–`H4`), и вручную их вводить не нужно.

### Какое из трёх меню выбрать

Приложение предлагает «Создать из файла или архива», «Создать из QR-кода» и
«Создать с нуля». Порядок выбора такой:

| Пункт меню | Когда выбирать | Что подготовить |
|---|---|---|
| **2. Из QR-кода** | по умолчанию, самый быстрый путь | `client1.png` или QR на экране терминала |
| **1. Из файла или архива** | если камера не берёт QR или QR не сгенерировался | `client1.conf` (можно `.zip` с ним) |
| **3. С нуля** | только если нет ни файла, ни QR (например, конфиг потерялся) | данные из `client1.conf` — вводятся руками, 9 параметров обфускации обязательно |

Не выбирайте «с нуля», если есть файл/QR: там нужно безошибочно ввести
`Jc, Jmin, Jmax, S1, S2, H1–H4`, а любая опечатка = сервер молча отбрасывает пакеты.

### Меню 2 → «Создать из QR-кода» (быстрее всего)

QR делается **на сервере** по SSH (там лежат конфиги с ключами), а не на телефоне
и не на сторонних сайтах «сгенерировать QR онлайн» — туда нельзя отдавать
приватный ключ.

```bash
# QR уже лежит рядом с конфигом после установки
ls ~/awg-clients/client1.png

# в любой момент заново напечатать QR в терминале (по SSH) и обновить PNG
bash amneziawg/qr.sh client1
bash amneziawg/qr.sh client1 --png ~/tunnel.png     # свой путь для картинки
bash amneziawg/qr.sh /root/ru-mobile/awg-443/client1.conf --text   # только текст
```

`qr.sh` сам находит конфиг (`~/awg-clients/`, `~/ru-mobile/awg-443/`, `~/ru-mobile/awg-2408/`,
текущий каталог), проверяет, что в нём есть `[Interface]`, ключи, `[Peer]`, `Endpoint`
и все параметры обфускации, и только потом показывает QR.

В приложении:

1. AmneziaVPN → «+» (или «Добавить туннель») → **сканировать QR-код**;
   AmneziaWG → «+» → «Сканировать QR-код».
2. Навести камеру на QR с экрана или из `client1.png`.
3. Проверить, что появились параметры обфускации (Jc, Jmin, Jmax, S1, S2, H1–H4) —
   если приложение их не показало, значит отсканировался не тот QR.
4. Подключиться, затем проверить на сервере: `awg show` (должно появиться рукопожатие).

Если сканер «не видит» QR (длинный конфиг + дешёвая камера) — откройте PNG на
компьютере и сканируйте с большего экрана, либо используйте пункт меню 1 (файл).

> Если в вашей версии AmneziaVPN нет пункта со сканером QR — это нормально:
> QR сканирует приложение **AmneziaWG** (Android/iOS), а в AmneziaVPN используйте
> импорт файла (пункт меню 1) или ручной ввод (пункт меню 3). Конфиг один и тот же.

### Меню 1 → «Создать из файла или архива»

Нужен сам файл конфига (или архив с ним):

```bash
# скачать PNG и CONF с сервера на свой компьютер
scp root@IP_СЕРВЕРА:/root/ru-mobile/awg-443/client1.png .
scp root@IP_СЕРВЕРА:/root/ru-mobile/awg-443/client1.conf .
```

Дальше: AmneziaVPN → «Добавить туннель» → «Импорт из файла» → выбрать `client1.conf`.
В AmneziaWG: «+» → «Создать из файла или архива» → указать `client1.conf` или `.zip`
с ним. Работает всегда, камера не нужна.

На телефон проще всего перекинуть файл через «Избранное» в мессенджере, облако
или кабелем — и выбрать его в приложении.

### Меню 3 → «Создать с нуля» (если двух первых нет под рукой)

Протокол **AmneziaWG**, поля берутся из `client1.conf`:

| Поле приложения | Строка в конфиге |
|---|---|
| Адрес сервера / порт | `Endpoint = IP:порт` |
| Приватный ключ клиента | `PrivateKey` |
| Публичный ключ сервера | `PublicKey` (в секции `[Peer]`) |
| Адрес клиента в туннеле | `Address` (например `10.8.1.2`) |
| DNS | `DNS` |
| MTU | `MTU` |
| Jc, Jmin, Jmax, S1, S2, H1–H4 | одноимённые строки в `[Interface]` |

Параметры обфускации должны совпасть с сервером **точно** — иначе рукопожатие
не пройдёт (сервер молча отбросит пакеты). Проще всё же взять QR.

### Проверка, что туннель добавился правильно

1. В приложении у туннеля есть поля `Jc/Jmin/Jmax/S1/S2/H1–H4` (значения не пустые).
2. Порт совпадает с тем, что на сервере: например `443` или `2408`.
3. После подключения на сервере `awg show` показывает свежее рукопожатие (latest handshake).
4. Если рукопожатия нет — почти всегда не совпали параметры обфускации или порт;
   пересоздайте туннель из файла/QR, а не «с нуля».

## VLESS + REALITY

Ссылка выглядит так:

```
vless://UUID@IP:443?encryption=none&flow=xtls-rprx-vision&security=reality&sni=www.microsoft.com&fp=chrome&pbk=ПУБЛИЧНЫЙ_КЛЮЧ&sid=SHORTID&spx=%2F&type=tcp#vpnbye-1
```

| Платформа | Приложение | Как импортировать |
|---|---|---|
| Android | v2rayNG, NekoBox, Hiddify | «+» → «Импорт из буфера обмена» или скрин QR |
| iOS | Streisand, FoXray, Hiddify | то же (бесплатных в RU App Store может не быть — нужен зарубежный Apple ID) |
| Windows | Hiddify, v2rayN, NekoRay | Ctrl+V в окне приложения |
| macOS | Hiddify, FoXray | вставить ссылку |
| Linux | Hiddify, nekoray, xray-core | `xray run -c client.json` (тот же inbound/outbound) |

Импорт ссылки — самый удобный путь: ничего вручную не переносите.

## Полезные советы

* **Kill switch.** В WireGuard-клиентах для Android/iOS включите «Block non-tunnel
  traffic» / «On-demand», чтобы при обрыве трафик не уходил в открытую сеть.
* **Split tunneling.** `AllowedIPs = 0.0.0.0/0` — весь трафик в VPN.
  Нужен доступ только к домашней сети? Замените на `AllowedIPs = 192.168.1.0/24`
  (или сразу ставьте сервер с `--lan-only --lan 192.168.1.0/24`: тогда конфиг
  клиента уже будет ограничен туннелем и вашей LAN, а интернет пойдёт напрямую —
  и kill switch не нужен).
* **Один конфиг = один человек.** Не передавайте друзьям свой `client1.conf`:
  у каждого должен быть свой пир (в WG это `add-client.sh`, у Xray — свой UUID),
  иначе невозможно отозвать доступ без «перевыпуска» всем.
* **MTU.** Если сайты открываются «наполовину» (страница грузится, картинки нет) —
  уменьшите `MTU` в конфиге клиента: 1420 → 1380 → 1280.
