# 2. Сервер: где взять, сколько стоит, как защитить

## Что нужно от VPS

| Параметр | Минимум | Комфорт |
|---|---|---|
| CPU | 1 vCPU | 1–2 vCPU |
| RAM | 512 МБ | 1 ГБ |
| Диск | 10 ГБ | 20 ГБ |
| Трафик | 1 ТБ/мес | безлимит |
| Локация | Нидерланды, Германия, Финляндия, Швеция | + США/Азия для стриминга |
| Цена | 3–5 €/мес | 5–10 €/мес |

Один такой сервер спокойно держит 5–20 клиентов и 100+ Мбит/с.

## Где брать

* **Hetzner** (Германия/Финляндия) — от ~4 €, лучший баланс цены и качества.
* **Aeza / 4vps / VDSina** — принимают карты РФ, локации NL/DE/FI.
* **Contabo** — дешёвая память, но сеть медленнее.
* **DigitalOcean / Vultr / Linode** — от 5 $, удобно, но дороже за трафик.

Практика: **не берите хостинг в стране, из которой нужно «выходить»**, и не берите
IP, который уже засветился как VPN (проверка — `curl ifconfig.me`, затем
`ping`/`mtr` с клиента). Если IP заблокирован — у большинства хостеров
можно за пару долларов сменить/пересоздать IP (или сразу взять «floating IP»).

## Первичная настройка (5 минут)

```bash
# 1. Входим по SSH
ssh root@IP_СЕРВЕРА

# 2. Обновляем систему
apt update && apt upgrade -y

# 3. Ключи SSH вместо пароля (выполнить НА СВОЁМ компьютере)
ssh-keygen -t ed25519 -C "vpn"            # если ключа ещё нет
ssh-copy-id -i ~/.ssh/id_ed25519.pub root@IP_СЕРВЕРА
```

Затем на сервере — запретить вход по паролю:

```bash
nano /etc/ssh/sshd_config
#   PasswordAuthentication no
#   PermitRootLogin prohibit-password
systemctl restart ssh
```

⚠️ Перед этим проверьте, что вход по ключу работает в **новом** окне терминала,
иначе можно потерять доступ к серверу.

## Firewall и fail2ban

```bash
apt install -y ufw fail2ban
ufw default deny incoming
ufw default allow outgoing
ufw allow 22/tcp          # SSH — лучше сразу ограничить: ufw allow from ВАШ_IP to any port 22
ufw allow 51820/udp       # WireGuard / AmneziaWG
# ufw allow 443/tcp       # для Xray REALITY
ufw enable
ufw status verbose
```

Скрипты из этого репозитория сами открывают нужный порт, если `ufw` уже включён.

## Гигиена

* Отключите IPv6 на сервере, если он вам не нужен, — меньше сюрпризов с утечками:
  `net.ipv6.conf.all.disable_ipv6 = 1` в `/etc/sysctl.d/99-noipv6.conf`.
* Держите систему обновлённой: `apt install -y unattended-upgrades`.
* Не храните клиентские конфиги на сервере дольше нужного — они равны паролю.
* Резервная копия: `/etc/wireguard/`, `/usr/local/etc/xray/`, ваши клиентские файлы
  (в зашифрованном виде, например `age` или `gpg`).
