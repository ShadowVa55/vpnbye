# 0. Начать с нуля (объяснение простыми словами)

Если вы раньше не настраивали серверы — читайте только эту страницу. Всё остальное
в `docs/` понадобится позже, если захотите разбираться.

## Что мы вообще делаем

Вы арендуете **чужой компьютер за границей** (он называется «сервер» или «VPS»),
на нём включаете VPN, а на телефон ставите приложение. Телефон соединяется с этим
компьютером, и для всех сайтов вы выглядите как иностранец.

**QR-код** — это «пропуск». Вы его создаёте на сервере, показываете телефону,
и приложение по нему настраивается само. Руками ничего вводить не нужно.

Три предмета, которые надо различать:

| Что это | Простыми словами |
|---|---|
| Сервер (VPS) | компьютер за 300–500 ₽/мес в другой стране, вы им управляете с клавиатуры |
| SSH | «окно в терминале», через которое вы пишете команды этому компьютеру |
| Приложение AmneziaWG | программа на телефоне, которая и есть ваш VPN-клиент |

## Что понадобится

* 300–500 ₽ в месяц (карта РФ подходит для Aeza, 4vps, VDSina).
* 30–40 минут.
* Телефон и компьютер.

## Шаг 1. Купить сервер (10 минут)

Делаем на примере **aeza.net** (принимает карты РФ; на 4vps.su шаги те же).

**1.1. Регистрация.** Заходите на aeza.net → «Регистрация» → почта и пароль →
подтвердите письмо (кнопка в письме).

**1.2. Пополнить баланс.** В панели найдите «Баланс» / «Пополнить» → карта РФ →
хватит **300–500 ₽** на первый месяц.

**1.3. Создать сервер.** Кнопка «Создать сервер» / «Новый сервер» и заполняем.
В некоторых панелях (например, где есть «ispmanager») отдельной кнопки нет —
тогда сервер заказывается так: **«Добавить услугу» (плюсик) → «Виртуальный сервер»**.

| Поле | Что выбрать |
|---|---|
| Локация / страна | **Швеция (Стокгольм)**, Нидерланды, Германия или Финляндия — **не Россия!** |
| Тариф | самый дешёвый: **1 ядро, 1 ГБ памяти** |
| Операционная система (образ) | **Ubuntu 24.04** (если нет — 22.04) |
| Имя сервера | любое, например `vpn` |
| Остальное | не трогаем |

Жмём «Создать» / «Заказать».

**1.4. Подождать 1–5 минут.** Сервер создаётся не мгновенно: статус будет
**«активация»** / «Ожидание активации», а кнопки «Перезагрузить», «Продлить» —
серыми. Это нормально, просто обновите страницу через пару минут.

Когда статус станет **«активен»** (зелёная точка), в панели появится:

* **IP-адрес** — например `203.0.113.45` (обычно вверху карточки сервера,
  в «Мои услуги» или в письме на почту);
* **логин** — `root`;
* **пароль** — длинный набор букв и цифр. В панели он скрыт точками: нажмите
  иконку копирования рядом с полем «Пароль» и вставьте в заметки.

> Скопируйте пароль сразу в заметки. Если потеряли — в панели есть
> «Сменить пароль» / «Переустановить», это не проблема.
> Не нажимайте «Переустановить» без необходимости: она стирает всё на сервере.

**1.5. Проверка, что всё готово.** У вас на руках должно быть три вещи:

```
IP:     203.0.113.45
логин:  root
пароль: Xy7... (длинный)
```

Если названия кнопок в панели немного другие — ориентируйтесь на слова
«Создать сервер», «Локация», «Образ»/«ОС», «Баланс».

## Шаг 2. Открыть «окно управления» сервером (5 минут)

Проще всего с телефона: приложение **Termius** (бесплатное). Или с компьютера:
Windows → «PowerShell», Mac → «Терминал».

**Вариант А — с телефона (Termius):**

1. Установите Termius из Google Play / App Store, откройте.
2. «New Host» / «+» → в поле **Address** вставьте IP сервера.
3. **Username**: `root`, **Password**: пароль из панели.
4. «Save» → нажмите на созданное подключение. Появится чёрное окно с текстом —
   это и есть SSH.

**Вариант Б — с компьютера:** откройте PowerShell (Windows) или Терминал (Mac) и введите:

```bash
ssh root@IP_ИЗ_ПИСЬМА
```

* спросит `yes/no` — напишите `yes` и Enter;
* спросит пароль — вставьте пароль из письма (при вводе он **не отображается**, это нормально) и Enter.

Если увидели строку вида `root@vpn:~#` — вы «внутри» сервера. Всё, дальше только
копировать и вставлять команды.

## Шаг 3. Установить VPN (10 минут)

**Сначала:** репозиторий должен быть доступен серверу без пароля.

* Если репозиторий **публичный** — просто клонируйте, как ниже.
* Если **приватный** — либо переключите его на публичный
  (GitHub → ваш репозиторий → **Settings** → самый низ, «Danger Zone» →
  **Change visibility** → «Change to public», подтвердить), либо клонируйте по токену:
  `git clone https://ТОКЕН@github.com/ShadowVa55/vpnbye.git`.
  Секретов (ключей, паролей) в репозитории нет — только скрипты и документация.

Скопируйте и вставьте эти 4 строки по одной (каждую — Enter):

```bash
apt update && apt install -y git
git clone https://github.com/ShadowVa55/vpnbye.git
cd vpnbye
bash scripts/install-for-ru-mobile.sh
```

Последняя команда работает 5–10 минут и печатает много текста — это нормально.
Может спросить `Do you want to continue? [Y/n]` — нажмите Enter.

В конце появится **квадрат из точек** — это и есть QR-код. И строка вида:

```
==> Готово. Клиентские файлы: /root/ru-mobile
```

## Шаг 4. Забрать QR-код

Если QR в терминале выглядит «кракозябрами» (так бывает в PuTTY) — не страшно:

```bash
bash amneziawg/qr.sh client1
```

Команда нарисует QR заново и скажет путь к картинке:

```
==> PNG: /root/ru-mobile/awg-443/client1.png
```

Эту картинку можно отправить себе в Telegram («Избранное») и открыть на телефоне,
либо просто навести телефон на экран компьютера.

## Шаг 5. Подключить телефон (2 минуты)

1. Установите **AmneziaWG** из Google Play / App Store
   (или **AmneziaVPN**, если AmneziaWG не находится).
2. Нажмите «+» → **«Создать из QR-кода»**.
3. Наведите камеру на QR с экрана или на картинку.
4. Появится туннель → нажмите «Подключить», разрешите добавление VPN-профиля.
5. Проверка: откройте в браузере телефона **2ip.ru** — страна должна быть зарубежной,
   а не Россия.

Всё. Вы в VPN.

## Вариант: всё делаем с телефона (Android/iPhone)

Нюанс: QR-код, нарисованный на том же экране, отсканировать не получится.
Поэтому с телефона мы **скачиваем файл конфига** и добавляем туннель из файла.

**Ш1. Установите два приложения** из Google Play / App Store:

* **Termius** — чтобы зайти на сервер;
* **AmneziaWG** — сам VPN (если не находится, ставьте **AmneziaVPN**).

**Ш2. Termius → добавить сервер:**

Где кнопка: внизу экрана вкладка **Hosts** → кнопка **«+»** в правом нижнем углу
(на пустом экране — «Add your first host»). Termius может попросить создать
аккаунт — это необязательно, можно взять другой клиент (см. ниже).

На iPhone/iPad экран называется **«New Host»**, заполнять нужно только 4 поля
(остальные — «Parent Group», «Tags», «AI Agent», «TELNET», «Mosh» — не трогаем):

| Поле на экране | Что вписать |
|---|---|
| **Label** | `vpn` (просто имя, можно пропустить) |
| **IP or Hostname** *(Required)* | IP сервера, например `82.148.227.178` |
| **Port** (в блоке SSH) | оставить `22` |
| **Username** | `root` |
| **Password** | пароль из панели хостера |

Сохранить — **галочка «✓» в правом верхнем углу**. Потом тапнуть по появившемуся
хосту `vpn` и на запрос ключа нажать **Accept**.

| Поле | Значение |
|---|---|
| Address / Hostname | IP вашего сервера |
| Username | `root` |
| Password | пароль из панели хостера |

**Если Termius неудобен — поставьте JuiceSSH** (без регистрации, бесплатно):

1. Откройте JuiceSSH → вкладка **Connections** → «**+**» → **SSH**.
2. **Nickname**: `vpn`; **Address**: IP сервера; **Identity** → «New» →
   **Username**: `root`, **Password**: пароль из панели → сохранить.
3. Нажмите на созданное подключение → «Accept» на запрос отпечатка.

Ещё варианты: **ConnectBot** (совсем простой) или **Termux** (`pkg install openssh`,
дальше `ssh root@IP`).

> Подойдёт **любой** SSH-клиент: Termius, JuiceSSH, ConnectBot, Termux,
> «Terminal — Modern SSH Client» и т. п. Требования всего три: можно указать
> адрес (Host/IP), порт (22), пользователя (`root`) и пароль.
> Не платите подписку и не создавайте аккаунт ради этого; если приложение просит
> доступ к контактам/SMS — удалите и возьмите JuiceSSH.

Нажмите **Save** → затем тапните по созданному хосту (Connect). Если спросит
про ключ/отпечаток — **Accept / Доверять**.

Появится чёрный экран с текстом, в конце строка `root@...:~#` — вы на сервере.

**Ш3. Вставьте четыре команды** по одной (в Termius вставка: нажать и удерживать
поле ввода → **Paste**):

```
apt update && apt install -y git
git clone https://github.com/ShadowVa55/vpnbye.git
cd vpnbye
bash scripts/install-for-ru-mobile.sh
```

Последняя работает 5–10 минут. **Не выключайте экран и не сворачивайте Termius.**
В конце появится квадрат из точек (QR) и строка `/root/ru-mobile`.

**Ш4. Скачайте файл конфига на телефон.** В Termius в открытой сессии нажмите
иконку **папки / SFTP** (или меню «…» → Files):

1. перейдите в `/root/ru-mobile/awg-443/`;
2. нажмите на `client1.conf` → **Download / Скачать** (файл попадёт в «Загрузки»);
3. при желании повторите для `awg-2408/client1.conf` (это резервный канал).

**Ш5. AmneziaWG:** «+» → **«Создать из файла или архива»** → выберите скачанный
`client1.conf` → туннель появится в списке → нажмите «Подключить» и разрешите
системе добавить VPN-профиль.

> ⚠️ Важно: три кнопки «Создать из файла или архива / из QR-кода / с нуля» —
> это уже **VPN-приложение**. Если у вас пока нет ни файла `client1.conf`, ни
> QR-кода, значит установка на сервере ещё не сделана (шаги Ш1–Ш4). Приложение
> для управления сервером — это **Termius / JuiceSSH**, другое приложение.

**Ш6. Проверка:** откройте в браузере телефона **2ip.ru** — страна должна быть
Швеция, а не Россия.



| Что вижу | Что делать |
|---|---|
| `Permission denied` при входе | пароль скопирован с ошибкой; копируйте из письма целиком |
| `command not found: git` | повторите `apt update && apt install -y git` |
| QR не сканируется | откройте PNG на компьютере и сканируйте с экрана; если не выходит — в приложении выберите «Создать из файла» и укажите `client1.conf` |
| Туннель подключился, но сайты не грузятся | с телефона включите мобильный интернет вместо Wi-Fi; если не помогло — `bash amneziawg/qr.sh client1` и попробуйте другой канал (файлы в `/root/ru-mobile/awg-2408/` и `/root/ru-mobile/reality/`) |
| Сайты грузятся наполовину | в приложении в настройках туннеля поставьте MTU `1280` |

Проверить сервер в любой момент:

```bash
sudo bash scripts/preflight.sh
```

## Словарик

* **VPS / сервер** — арендованный компьютер в дата-центре.
* **SSH** — способ управлять этим компьютером текстовыми командами.
* **root** — «главный пользователь» сервера (у вас он один).
* **Туннель / профиль** — сохранённое подключение в приложении.
* **QR** — картинка, в которую «зашит» весь конфиг; сканируется камерой.
* **AmneziaWG** — вид VPN, который провайдеры в России не распознают.
* **MTU** — размер пакета; если интернет «половинчатый», его уменьшают.
